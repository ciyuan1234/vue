# Vue 学习课程

从零开始学习 Vue 3，每节课的代码和笔记都会同步到这个仓库。

## 课程大纲

| 阶段 | 课程 | 内容 | 状态 |
|------|------|------|------|
| 基础 | 第 1 课 | 创建应用、模板语法、指令入门 | ✅ |
| 基础 | 第 2 课 | 响应式、事件处理、表单绑定 | ⬜ |
| 基础 | 第 3 课 | 计算属性、侦听器、Class 与 Style 绑定 | ⬜ |
| 基础 | 第 4 课 | 条件渲染、列表渲染、v-model | ⬜ |
| 基础 | 第 5 课 | 组件基础、Props 与 Emits | ⬜ |
| 进阶 | 第 6 课 | 生命周期、Composition API、setup 语法糖 | ⬜ |
| 进阶 | 第 7 课 | Vue Router 多页面应用 | ⬜ |
| 进阶 | 第 8 课 | Pinia 状态管理 | ⬜ |
| 进阶 | 第 9 课 | 组合式函数、组件通信进阶 | ⬜ |
| 实战 | 第 10 课 | 综合实战：Todo 待办清单 | ⬜ |

## 学习方式

- 每节课一个文件夹：`lesson-XX-课程名/`
- 每个文件夹包含 `index.html`（或 Vite 工程）和 `NOTES.md`（知识点笔记）
- 基础阶段使用 CDN 引入 Vue，双击 `index.html` 即可在浏览器中运行
- 进阶阶段切换为 Vite + Vue 3 工程模式

## 环境要求

- 任意现代浏览器
- Node.js 20+（进阶阶段需要）
- Git
